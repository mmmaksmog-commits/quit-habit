# 🌱 Без привычки

**Трекер отказа от курения, сладкого, соцсетей и других привычек.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/quit-habit/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Живой таймер и сэкономленные деньги
- Этапы восстановления (для курения — по данным ВОЗ)
- Что можно купить на сэкономленное
- Несколько привычек, срывы и рекорды

## Стек

JavaScript, localStorage. Один файл `index.html`, без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/quit-habit.git
cd quit-habit
python3 -m http.server 8000
```
